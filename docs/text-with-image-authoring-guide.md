# Text with Image Authoring

Text with Image pairs a text panel with either a responsive editorial image or a layered gift-card image composition. Choose the variation that matches the content, then complete the fields shown for that variation.

## Shared fields

- **Image Position**: Choose **Image on Right** or **Image on Left**. The default is **Image on Right**. On mobile, the text and image stack vertically.
- **Eyebrow Text**: Optional short label displayed above the title.
- **Title**: Required rich-text heading. Keep it concise; paragraph breaks in the title are displayed as separate lines.
- **Description**: Optional rich text displayed below the title.
- **CTA Text** and **CTA Link**: Optional. Provide both to display the text link. When a CTA link is provided, the image is linked to the same destination as well.
- **CTA Open in new tab**: Optional; applies to both the text CTA and linked image. Defaults to off.
- **Block ID**: Optional anchor ID for linking to this block. Use a unique, URL-friendly value such as `about-capella`.

## Little Stars variation

Use **Little Stars** for a single editorial image with an optional mobile-specific asset.

- **Desktop/Tablet Asset**: Required. Select the primary image.
- **Desktop/Tablet Asset Alt Text**: Required. Describe the image meaningfully for visitors using assistive technology.
- **Mobile Asset**: Optional. Select a cropped or composed image intended for screens up to 767px wide. If omitted, the primary image is used at all screen sizes.
- **Mobile Asset Alt Text**: Optional. If omitted, the desktop/tablet alt text is used on mobile.

The image displays beside the text on larger screens and below the text on mobile. On mobile, it fills a 4:5 image area, so choose assets that still read well with a portrait crop.

## Gift Card variation

Use **Gift Card** to display a composed stack of gift-card artwork. The block supports one to three images; the composition changes to suit the number of images.

- **Gift Card Image 1**: Required. This is the only required image in the stack.
- **Gift Card Image 1 Alt Text**: Required. Describe the first image for assistive technology.
- **Gift Card Image 2** and **Gift Card Image 3**: Optional. Add these to create a two- or three-image stack. Leave an image field empty when it is not needed.
- **Gift Card Image 2 Alt Text** and **Gift Card Image 3 Alt Text**: Optional. Add meaningful descriptions when the corresponding images are used.

Gift Card does not have separate mobile image fields; its image composition is adapted for mobile automatically. Select **Image Position** independently to place the composition on the left or right on larger screens.

## Before publishing

- Choose the variation before selecting its assets; the editor shows only the fields for the selected variation.
- Add alt text for every image that conveys information. If an image is purely decorative, use an empty alt value when the editor permits it.
- Preview the block at desktop and mobile widths, especially when using a mobile-specific Little Stars asset or multiple gift-card images.
- If adding a CTA, verify both the text link and the linked image lead to the intended destination.
